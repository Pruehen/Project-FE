조작법 (임시)
이동 : WASD
상호작용 : 마우스 좌클릭 (선택), 우클릭 (채취)
건설 도구 탭 선택 : 상단 키패드 1~0, 하단 아이콘 버튼 클릭
건설 : 마우스 좌클릭
건설 중 건물 회전 : R
캐릭터 인벤토리 토글 : TAB, I
모든 인벤토리 닫기 : ESC
캐릭터 제작 UI 토글 : E

임시 저장 키 : V - 잠시 비활성화 
임시 불러오기 키 : L - 잠시 비활성화 

구현 목표 기능 : 팩토리오 레퍼런스
인벤토리 클릭 : 아이템 선택. 건설 가능 아이템의 경우 자동으로 빌딩 모드로 진입. 퀵슬롯에 놓인 아이템의 경우, 키보드 다운 혹은 클릭으로 아이템 선택.
아이템 선택 상태에서 : 빈 슬롯 클릭시 아이템 드랍. 아이템이 있는 슬롯 선택 시 아이템 스왑. 퀵슬롯 선택 시 퀵슬롯에 아이템 등록
퀵슬롯 우클릭 : 아이템 등록 제거

===================================================
이슈 : 광맥의 동적 생성 문제
광맥의 잔여 수량을 저장하기 위해서는 저장 데이터를 불러와서 동적으로 생성하는 로직이 포함되어야 함.
하지만 그럴 경우 씬에 미리 배치해놓은 광맥과 충돌하게 됨.
배치해놓은 광맥과 저장한 광맥이 동일한지 검사한 후 수량만 변경하는 방법도 고민해볼 수 있으나 시간이 다소 소요될 것으로 보임.

결론 : 광맥 랜덤 생성 기능과 함께 광맥 저장 기능을 구현하는 것으로 결정. (새티스팩토리처럼 무한 광맥을 고정된 자리에 배치하는 경우도 생각해볼 수 있음)

구현 예정
저장 기능 : 건물의 레시피 상태, 진행도, 보유 인벤토리를 저장할 것 (플레이어 인벤토리의 저장을 응용)
